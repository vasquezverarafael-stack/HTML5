Ejercicio 7.13: Ingresos de un vendedor

1. Enunciado del problema

Una empresa paga a sus vendedores $200 por semana, más el 9% de sus ventas brutas durante esa semana. Se conocen los siguientes valores de los artículos vendidos:

Artículo Valor
1 $239.99
2 $129.75
3 $99.95
4 $350.89

Desarrolle una secuencia de comandos que reciba como entrada los artículos vendidos por un vendedor durante la última semana, calcule sus ingresos y muestre el resultado en HTML.

2. Algoritmo en pseudocódigo

Inicio
    sueldoBase = 200
    totalVentas = 0

    Repetir para cada artículo
        Preguntar si vendió el artículo
        Si la respuesta es sí
            totalVentas = totalVentas + valor del artículo
        Fin Si
    Fin Repetir

    comision = totalVentas * 0.09
    ingresos = sueldoBase + comision

    Mostrar totalVentas
    Mostrar comision
    Mostrar ingresos
Fin

3. Refinamiento arriba-abajo

  1. Definir el sueldo base semanal de $200.
  2. Registrar los valores de los cuatro artículos.
  3. Preguntar al vendedor cuántas unidades vendió de cada artículo.
  4. Multiplicar cada cantidad por el precio correspondiente.
  5. Sumar los importes para obtener las ventas brutas.
  6. Calcular la comisión multiplicando las ventas por 0.09.
  7. Sumar la comisión al sueldo base.
  8. Mostrar las ventas, la comisión y los ingresos totales.

4. Programa en JavaScript

Introduzca la cantidad de unidades vendidas de cada artículo. Si no vendió un artículo, escriba 0.

6. Conclusión

El programa calcula las ventas brutas según las cantidades vendidas de cada artículo, obtiene el 9% de comisión y lo suma al sueldo base semanal de $200 para determinar los ingresos totales del vendedor.
