Ejercicio 7.23: Descifrar datos

Enunciado

Escriba una secuencia de comandos que reciba un entero cifrado de cuatro dígitos y lo descifre para obtener el número original, utilizando el procedimiento inverso del ejercicio 7.22.

Algoritmo en pseudocódigo

Inicio
    Leer numero cifrado de cuatro dígitos

    Separar los cuatro dígitos

    Intercambiar el primer dígito con el tercero
    Intercambiar el segundo dígito con el cuarto

    Para cada dígito
        digito = (digito + 3) MOD 10
    Fin Para

    Mostrar numero original
Fin

Refinamiento descendente

  1. Solicitar el número cifrado de cuatro dígitos.
  2. Validar que la entrada tenga exactamente cuatro dígitos.
  3. Separar los cuatro dígitos.
  4. Deshacer los dos intercambios de posiciones.
  5. Sumar 3 a cada dígito y calcular el módulo 10.
  6. Mostrar el número original recuperado.

Prueba de escritorio

Etapa Resultado
Número cifrado 0981
Deshacer los intercambios 8901
Sumar 3 y aplicar módulo 10 1234

Conclusión

El programa recupera el número original deshaciendo los intercambios y aplicando la operación inversa a cada dígito. Se utiliza una cadena de texto para conservar los ceros iniciales.
