Ejercicio 7.19: Problema del else suelto

a) Sin llaves

if (x < 10)
    if (y > 10)
        document.writeln("*****");
    else
        document.writeln("#####");

document.writeln("$$$$$");

Pruebas del inciso a)

b) Con llaves

if (x < 10) {
    if (y > 10)
        document.writeln("*****");
    else {
        document.writeln("#####");
        document.writeln("$$$$$");
    }
}

Pruebas del inciso b)

Conclusión

En el inciso a), el else se asocia con el if más cercano, que es la condición y > 10. En el inciso b), las llaves delimitan el bloque del else y determinan qué instrucciones se ejecutan cuando la condición interna es falsa.
