Ejercicio 7.15: Encontrar el número más grande

Enunciado

Escriba un algoritmo en pseudocódigo y una secuencia de comandos que reciba diez números de un solo dígito, determine el mayor de ellos y muestre un mensaje con el número más grande. El programa debe utilizar las variables contador, numero y mayor.

Algoritmo en pseudocódigo

Inicio
    contador = 1

    Leer numero
    mayor = numero

    Mientras contador < 10
        Leer numero

        Si numero > mayor Entonces
            mayor = numero
        Fin Si

        contador = contador + 1
    Fin Mientras

    Mostrar "El número más grande es: ", mayor
Fin

Refinamiento descendente

  1. Solicitar el primer número e inicializar mayor con ese valor.
  2. Inicializar el contador para registrar los números procesados.
  3. Solicitar los números restantes hasta completar diez.
  4. Comparar cada número con mayor.
  5. Actualizar mayor si el nuevo número es superior.
  6. Mostrar el número más grande encontrado.

Conclusión

El programa utiliza un contador para procesar diez números, la variable numero para almacenar cada entrada y la variable mayor para conservar el valor máximo encontrado. Al finalizar, muestra el número más grande de la serie.
