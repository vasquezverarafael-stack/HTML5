Ejercicio 7.17: Los dos números más grandes

Enunciado

Utilizando una metodología similar a la del ejercicio 7.15, encuentre los dos valores más grandes de los diez números introducidos. Cada número solo puede introducirse una vez.

Algoritmo en pseudocódigo

Inicio
    mayor = -1
    segundoMayor = -1
    contador = 1

    Mientras contador <= 10
        Leer numero

        Si numero > mayor Entonces
            segundoMayor = mayor
            mayor = numero
        Si no, si numero > segundoMayor Entonces
            segundoMayor = numero
        Fin Si

        contador = contador + 1
    Fin Mientras

    Mostrar mayor
    Mostrar segundoMayor
Fin

Refinamiento descendente

  1. Inicializar las variables mayor y segundoMayor.
  2. Solicitar diez números, uno por uno.
  3. Comparar cada número con el mayor actual.
  4. Si lo supera, mover el mayor anterior a segundoMayor.
  5. Si no supera al mayor, comprobar si supera a segundoMayor.
  6. Mostrar los dos valores encontrados.

Conclusión

El programa encuentra los dos números más grandes de diez entradas sin repetir la captura de ningún número. Para ello, compara cada valor con el mayor y el segundo mayor registrados hasta ese momento.
