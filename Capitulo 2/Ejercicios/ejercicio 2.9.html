Indique cuál de los siguientes enunciados es verdadero y cuál es falso. Si es falso, explique por qué.

a) Un documento de HTML5 válido no puede contener letras mayúsculas en nombres de elementos.

Respuesta: Falso. HTML5 permite usar letras mayúsculas o minúsculas en los nombres de los elementos, aunque se recomienda utilizar minúsculas.

b) Los documentos de HTML5 pueden tener la extensión de archivo .htm.

Respuesta: Verdadero. Los documentos de HTML5 pueden tener la extensión .html o .htm.

c) &less; es la referencia a entidad de carácter para el carácter menor que (<).

Respuesta: Falso. La referencia correcta para el carácter menor que (<) es &lt;.

d) En un documento de HTML5 válido, <u> puede anidarse directamente dentro de las etiquetas <ol> o <ul>.

Respuesta: Falso. Dentro de <ol> o <ul>, los elementos que deben aparecer directamente son <li>. Si se quiere usar <u>, debe colocarse dentro de un <li>.
