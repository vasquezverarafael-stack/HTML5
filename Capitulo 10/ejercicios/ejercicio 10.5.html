Ejercicio 10.5

Encuentre el o los errores en cada uno de los siguientes segmentos de programa y corríjalos.

a)

Segmento original:

var b = new Array( 10 );
var longitud = b.length;

for ( var i = 0; i <= longitud; ++i )
{
    b[ i ] = 1;
}

Error: se hace referencia al elemento de un arreglo fuera de los límites del arreglo (b[ 10 ]). El arreglo tiene 10 elementos, con índices del 0 al 9, pero con <= el ciclo también llega a i = 10. (Nota: en realidad éste es un error lógico y no sintáctico.)

Corrección: cambie el operador <= a <.

var b = new Array( 10 );
var longitud = b.length;

for ( var i = 0; i < longitud; ++i )
{
    b[ i ] = 1;
}

b)

Segmento original:

var a = [ [ 1, 2 ], [ 3, 4 ] ];
a[ 1, 1 ] = 5;

Error: el indexado de arreglos se realiza de manera incorrecta. En un arreglo bidimensional, cada índice va en sus propios corchetes.

Corrección: cambie la instrucción a a[ 1 ][ 1 ] = 5;

var a = [ [ 1, 2 ], [ 3, 4 ] ];
a[ 1 ][ 1 ] = 5;

Demostración

Resultado de ejecutar cada segmento, original y corregido:

En el inciso a), JavaScript no marca ningún error: al escribir en b[ 10 ] el arreglo simplemente crece. Por eso es un error lógico. En el inciso b), a[ 1, 1 ] usa el operador coma, que se queda con el último valor, así que equivale a a[ 1 ] = 5 y reemplaza toda la fila 1 por el número 5.
