Ejercicio 10.13

Etiquete los elementos del arreglo bidimensional de tres por cinco llamado ventas para indicar el orden en el que se deben establecer en cero mediante el siguiente segmento de programa:

for ( var fila in ventas )
{
    for ( var col in ventas[ fila ] )
    {
        ventas[ fila ][ col ] = 0;
    }
}

Respuesta

El ciclo externo recorre las filas (0, 1 y 2) y, por cada fila, el ciclo interno recorre todas sus columnas (0 a 4) de izquierda a derecha. Por lo tanto los elementos se ponen en cero fila por fila, empezando por la fila 0. Cada número de la tabla indica el orden en que se establece ese elemento en cero:

Orden en que se establece cada elemento en cero
columna 0columna 1columna 2 columna 3columna 4
fila 012345
fila 1678910
fila 21112131415

En otras palabras, el orden es ventas[ 0 ][ 0 ], ventas[ 0 ][ 1 ], ..., ventas[ 0 ][ 4 ], luego ventas[ 1 ][ 0 ], ..., ventas[ 1 ][ 4 ], y por último ventas[ 2 ][ 0 ], ..., ventas[ 2 ][ 4 ]. Es decir, el segundo índice (la columna) es el que cambia más rápido.
