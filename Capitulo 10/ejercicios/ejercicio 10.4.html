Ejercicio 10.4

Escribir instrucciones de JavaScript (con respecto al arreglo tabla) para realizar cada una de las siguientes tareas:

a) Declarar y crear el arreglo con tres filas y tres columnas.
b) Almacenar el número total de elementos en la variable totalElementos.
c) Usar una instrucción for...in para inicializar cada elemento del arreglo con la suma de sus índices de fila y de columna. Suponga que las variables x y y se declaran como variables de control.

Respuestas

a)

var tabla = new Array( new Array( 3 ), new Array( 3 ),
    new Array( 3 ) );

b)

var totalElementos = tabla.length * tabla[ 0 ].length;

Son 3 filas por 3 columnas, así que totalElementos vale 9.

c)

for ( var x in tabla )
{
    for ( var y in tabla[ x ] )
    {
        tabla[ x ][ y ] = x + y;
    }
}

Dos detalles sobre esta respuesta. En el libro la segunda línea del ciclo dice table[ x ], que es una errata: la variable se llama tabla. Además, con las variables del libro este código no logra lo que pide el enunciado, por estas razones:

  • new Array( 3 ) crea filas con tres posiciones vacías, y for...in omite los elementos sin definir (el propio libro lo advierte en el Tip para prevenir errores 10.2). El ciclo interno no se ejecuta ninguna vez y la tabla queda sin valores.
  • En un for...in, las variables x y y reciben los índices como cadenas ("0", "1", "2"). Entonces x + y concatena en lugar de sumar y daría "01", no 1. Para sumar hay que convertirlos con parseInt( x ) + parseInt( y ).

c) versión corregida (con ciclos for por índice)

for ( var x = 0; x < tabla.length; ++x )
{
    for ( var y = 0; y < tabla[ x ].length; ++y )
    {
        tabla[ x ][ y ] = x + y;
    }
}
