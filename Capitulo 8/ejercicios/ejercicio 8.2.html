Ejercicio 8.5

¿Qué es lo que hace el siguiente programa?

Programa

<!DOCTYPE html>

<!-- Ejercicio 8.5: ej08_05.html -->
<html>
<head>
    <meta charset = "utf-8">
    <title>Misterio</title>
    <script>

        document.writeln( "<table>" );

        for ( var i = 1; i <= 10; i++ )
        {
            document.writeln( "<tr>" );

            for ( var j = 1; j <= 5; j++ )
                document.writeln( "<td>(" + i + ", " + j + ")</td>" );

            document.writeln( "</tr>" );
        } // fin de for

        document.writeln( "</table>" );

    </script>
</head><body />
</html>

Respuesta

El programa crea una tabla HTML de 10 filas por 5 columnas (50 celdas). Cada celda muestra sus propias coordenadas en el formato (fila, columna).

  1. El document.writeln( "<table>" ) abre la tabla.
  2. El ciclo externo (i de 1 a 10) escribe una fila <tr> en cada vuelta.
  3. El ciclo interno (j de 1 a 5) escribe 5 celdas <td> dentro de esa fila, cada una con el texto (i, j).
  4. Al terminar el ciclo interno se cierra la fila con </tr>, y al terminar el externo se cierra la tabla.

La primera fila muestra (1, 1) (1, 2) (1, 3) (1, 4) (1, 5) y la última (10, 1) (10, 2) (10, 3) (10, 4) (10, 5). Como el programa original no define bordes, en el navegador se vería como una cuadrícula de texto sin líneas.
