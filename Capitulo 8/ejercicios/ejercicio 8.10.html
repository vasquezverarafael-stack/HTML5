Ejercicio 8.13

Dada la siguiente instrucción switch:

switch ( k )
{
    case 1:
        break;
    case 2:
    case 3:
        ++k;
        break;
    case 4:
        --k;
        break;
    default:
        k *= 3;
} // fin de switch

x = k;

¿Qué valores se asignan a x cuando k tiene valores de 1, 2, 3, 4 y 10?

Respuestas

Valor de kQué ocurre en el switchValor asignado a x
1 Entra a case 1, que solo tiene break. k no cambia. 1
2 Entra a case 2, que no tiene instrucciones ni break, así que continúa en case 3: ++k hace k = 3 y luego break. 3
3 Entra a case 3: ++k hace k = 4 y luego break. 4
4 Entra a case 4: --k hace k = 3 y luego break. 3
10 No coincide con ningún case, así que se ejecuta default: k *= 3 hace k = 30. 30

Los casos 2 y 3 comparten las mismas instrucciones porque case 2 no tiene break. Cuando k vale 2, la ejecución "cae" al case 3.
