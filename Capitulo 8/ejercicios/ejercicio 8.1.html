Ejercicio 8.4

Encuentre el error en cada uno de los siguientes segmentos de código. (Nota: puede haber más de un error).

a)

Segmento original:

For ( x = 100, x >= 1, ++x )
    document.writeln( x );

Errores:

  1. For debe ir en minúscula: for.
  2. Los tres elementos del encabezado se separan con punto y coma (;), no con comas.
  3. ++x incrementa, pero el ciclo cuenta hacia abajo de 100 a 1. Debe ser --x. Con ++x sería un ciclo infinito.
  4. (Buena práctica) Declarar la variable con var.

Corrección:

for ( var x = 100; x >= 1; --x )
    document.writeln( x );

b)

El siguiente código debe imprimirse sin importar si el valor entero es par o impar:

Segmento original:

switch ( valor % 2 )
{
    case 0:
        document.writeln( "Entero par" );
    case 1:
        document.writeln( "Entero impar" );
}

Error: falta break al final de cada case. Sin él, si el valor es par se imprimen "Entero par" y "Entero impar", porque la ejecución continúa con el siguiente caso.

Corrección:

switch ( valor % 2 )
{
    case 0:
        document.writeln( "Entero par" );
        break;
    case 1:
        document.writeln( "Entero impar" );
        break;
}

c)

El siguiente código debe imprimir los enteros impares del 19 al 1:

Segmento original:

for ( x = 19; x >= 1; x += 2 )
    document.writeln( x );

Error: el ciclo debe ir de 19 a 1 en orden descendente, pero x += 2 hace que x crezca, así que la condición x >= 1 nunca se vuelve falsa (ciclo infinito). Debe ser x -= 2.

Corrección:

for ( var x = 19; x >= 1; x -= 2 )
    document.writeln( x );

d)

El siguiente código debe imprimir los enteros pares del 2 al 100:

Segmento original:

contador = 2;
do {
    document.writeln( contador );
    contador += 2;
} While ( contador < 100 );

Errores:

  1. While debe ir en minúscula: while.
  2. La condición contador < 100 termina el ciclo cuando contador llega a 100, así que el 100 nunca se imprime. Debe ser contador <= 100.

Corrección:

var contador = 2;
do {
    document.writeln( contador );
    contador += 2;
} while ( contador <= 100 );

Resumen de errores

IncisoErrores
a)For en mayúscula, comas en lugar de ;, ++x en vez de --x
b)Faltan los break
c)x += 2 en vez de x -= 2 (ciclo infinito)
d)While en mayúscula, < en vez de <=
