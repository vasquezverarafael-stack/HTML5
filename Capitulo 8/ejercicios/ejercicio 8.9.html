Ejercicio 8.12

Suponga que i = 1, j = 2, k = 3 y m = 2. ¿Qué es lo que imprime cada una de las siguientes instrucciones? ¿Son necesarios los paréntesis en cada caso?

a) document.writeln( i == 1 );
b) document.writeln( j == 3 );
c) document.writeln( i >= 1 && j < 4 );
d) document.writeln( m <= 99 && k < m );
e) document.writeln( j >= i || k == m );
f) document.writeln( k + m < j || 3 - j >= k );
g) document.writeln( !( k > m ) );

Respuestas

IncisoExpresiónEvaluaciónImprime¿Paréntesis necesarios?
a) i == 1 1 == 1 es true true No
b) j == 3 2 == 3 es false false No
c) i >= 1 && j < 4 1 >= 1 es true y 2 < 4 es true, entonces true && true true No
d) m <= 99 && k < m 2 <= 99 es true, pero 3 < 2 es false, entonces true && false false No
e) j >= i || k == m 2 >= 1 es true, entonces el resultado es true (la segunda condición ni se evalúa) true No
f) k + m < j || 3 - j >= k 5 < 2 es false y 1 >= 3 es false, entonces false || false false No
g) !( k > m ) 3 > 2 es true, y !true es false false Sí

¿Por qué?

  • En los incisos a) a f) no hacen falta paréntesis. Los operadores aritméticos (+, -) tienen mayor precedencia que los relacionales (<, >=), estos mayor que los de igualdad (==), y todos mayor que && y ||. Cada comparación se evalúa primero, y después se combinan con el operador lógico.
  • En el inciso g) los paréntesis sí son necesarios. El operador ! tiene mayor precedencia que >, así que !k > m se evaluaría como (!k) > m. Eso compara false con 2, que no es lo que se quiere. Los paréntesis hacen que primero se evalúe k > m y después se niegue el resultado.
