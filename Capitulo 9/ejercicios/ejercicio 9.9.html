Ejercicio 9.16

Escriba segmentos de programa que realicen cada una de las siguientes tareas:

a) Calcule la parte entera del cociente cuando el entero a se divide entre el entero b.
b) Calcule el residuo entero cuando el entero a se divide entre el entero b.
c) Use las piezas de programa que se desarrollaron en las partes (a) y (b) para escribir una función llamada mostrarDigitos que reciba un entero entre 1 y 99999, para luego imprimirlo como una serie de dígitos, de los cuales cada par se separa mediante dos espacios. Por ejemplo, el entero 4562 debería imprimirse como: 4  5  6  2
d) Incorpore la función desarrollada en la parte (c) en una secuencia de comandos que reciba un entero de un diálogo prompt e invoque mostrarDigitos para pasar a la función el entero introducido.

a) Parte entera del cociente

cociente = Math.floor( a / b );

Por ejemplo, con a = 17 y b = 5, Math.floor( 17 / 5 ) da 3 (porque 17 / 5 = 3.4 y se descarta la parte decimal).

b) Residuo entero

residuo = a % b;

Por ejemplo, con a = 17 y b = 5, 17 % 5 da 2.

c) Función mostrarDigitos

function mostrarDigitos( numero )
{
    var divisor = 10000;
    var digito;
    var salida = "";

    while ( divisor > numero )
        divisor = divisor / 10;

    while ( divisor >= 1 )
    {
        digito = Math.floor( numero / divisor ); // parte (a)
        numero = numero % divisor;               // parte (b)

        if ( salida !== "" )
            salida += "&nbsp;&nbsp;";

        salida += digito;
        divisor = divisor / 10;
    } // fin de while

    return salida;
} // fin de la función mostrarDigitos

Para 4562 el divisor empieza en 1000 (porque 10000 es mayor que el número) y el ciclo hace lo siguiente:

  • 4562 / 1000 da 4, y el residuo es 562.
  • 562 / 100 da 5, y el residuo es 62.
  • 62 / 10 da 6, y el residuo es 2.
  • 2 / 1 da 2, y el residuo es 0.

Los dígitos se van juntando en salida separados por dos espacios. El primer while evita imprimir ceros a la izquierda.
