Ejercicio 9.11

Escriba instrucciones que asignen enteros aleatorios a la variable n en los siguientes rangos:

a) 1 ≤ n ≤ 2
b) 1 ≤ n ≤ 100
c) 0 ≤ n ≤ 9
d) 1000 ≤ n ≤ 1112
e) −1 ≤ n ≤ 1
f) −3 ≤ n ≤ 11

Respuestas

IncisoRangoInstrucciónEjemplo
a) 1 ≤ n ≤ 2 n = Math.floor( 1 + Math.random() * 2 );
b) 1 ≤ n ≤ 100 n = Math.floor( 1 + Math.random() * 100 );
c) 0 ≤ n ≤ 9 n = Math.floor( Math.random() * 10 );
d) 1000 ≤ n ≤ 1112 n = Math.floor( 1000 + Math.random() * 113 );
e) −1 ≤ n ≤ 1 n = Math.floor( -1 + Math.random() * 3 );
f) −3 ≤ n ≤ 11 n = Math.floor( -3 + Math.random() * 15 );

¿Cómo se obtienen?

Todas siguen la misma forma:

n = Math.floor( primerValor + Math.random() * cantidadDeValores );

  • primerValor es el entero más pequeño del rango (el desplazamiento).
  • cantidadDeValores es cuántos enteros hay en el rango: maximo - minimo + 1 (el factor de escala). Por ejemplo, de 1000 a 1112 hay 113 valores; de −3 a 11 hay 15.
  • Math.floor redondea hacia abajo para obtener un entero.
