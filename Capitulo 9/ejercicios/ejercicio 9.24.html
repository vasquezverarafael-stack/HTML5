Ejercicio 9.30

¿Qué hace la siguiente función?

// El parámetro b debe ser entero
// positivo para evitar recursividad infinita
function misterio( a, b )
{
    if ( b == 1 )
        return a;
    else
        return a + misterio( a, b - 1 );
}

Respuesta

La función misterio( a, b ) multiplica a por b, y lo hace con sumas repetidas: suma a consigo mismo b veces. Es una función recursiva:

  • Caso base: si b == 1, devuelve a (a × 1 = a).
  • Paso de recursividad: en otro caso devuelve a + misterio( a, b - 1 ), es decir, a × b = a + a × ( b − 1 ).

Ejemplo paso a paso: misterio( 5, 3 )

LlamadaSe convierte en
misterio( 5, 3 )5 + misterio( 5, 2 )
misterio( 5, 2 )5 + misterio( 5, 1 )
misterio( 5, 1 )5 (caso base)

Al regresar de las llamadas: 5 + ( 5 + 5 ) = 15, que es 5 × 3.

¿Por qué b debe ser un entero positivo?

Cada llamada reduce b en 1 y la recursión se detiene cuando b llega a 1. Si b fuera 0, negativo o tuviera decimales (por ejemplo, 2.5), b nunca sería exactamente 1 y la función se llamaría sin parar. Por eso el comentario de la función dice que b debe ser un entero positivo "para evitar recursividad infinita".
