Ejercicio 11.1

Complete las siguientes oraciones:

a) Como JavaScript usa objetos para realizar muchas tareas, se conoce por lo común como ___________.
b) Todos los objetos tienen ___________ y exhiben ___________.
c) Los métodos del objeto ___________ nos permiten realizar muchos cálculos matemáticos comunes.
d) Al proceso de invocar (o llamar) al método de un objeto se le conoce como ___________.
e) Las literales de cadena o constantes de cadenas se escriben como una secuencia de caracteres en ___________ o ___________.
f) Los índices para los caracteres en una cadena empiezan en ___________.
g) Los métodos ___________ y ___________ de String buscan la primera y última ocurrencias de una subcadena en un objeto String, respectivamente.
h) Al proceso de dividir una cadena en tokens se le denomina ___________.
i) El procesamiento de fechas y horas puede realizarse con base en la ___________ o en el ___________ del Estándar de Tiempo Mundial.
j) El método ___________ de Date recibe como argumento una cadena que representa una fecha y hora, y devuelve el número de milisegundos transcurridos entre la medianoche del 1 de enero de 1970 y la fecha y hora especificadas.
k) Las aplicaciones Web pueden usar la propiedad ___________ del objeto window para almacenar hasta varios megabytes de datos de cadenas de pares clave/valor en la computadora del usuario y pueden acceder a estos datos a través de sesiones y pestañas del navegador.
l) Las aplicaciones Web que necesitan acceso a los datos de pares clave/valor para sólo una sesión de navegación y que deben mantener esos datos separados entre varias pestañas pueden usar la propiedad ___________ del objeto window.
m) Un selector ___________ de CSS3 selecciona el primer hijo de un elemento.
n) Un selector ___________ de CSS3 con el argumento "odd" selecciona los elementos hijos impares y uno con el argumento "even" selecciona los elementos hijos pares.

Respuestas

a) Como JavaScript usa objetos para realizar muchas tareas, se conoce por lo común como lenguaje de programación basado en objetos.

b) Todos los objetos tienen atributos y exhiben comportamientos.

c) Los métodos del objeto Math nos permiten realizar muchos cálculos matemáticos comunes.

d) Al proceso de invocar (o llamar) al método de un objeto se le conoce como enviar un mensaje al objeto.

e) Las literales de cadena o constantes de cadenas se escriben como una secuencia de caracteres en comillas dobles o comillas sencillas.

f) Los índices para los caracteres en una cadena empiezan en 0.

g) Los métodos indexOf y lastIndexOf de String buscan la primera y última ocurrencias de una subcadena en un objeto String, respectivamente.

h) Al proceso de dividir una cadena en tokens se le denomina tokenización.

i) El procesamiento de fechas y horas puede realizarse con base en la zona horaria local de la computadora o en el Tiempo Universal Coordinado (UTC) del Estándar de Tiempo Mundial.

j) El método parse de Date recibe como argumento una cadena que representa una fecha y hora, y devuelve el número de milisegundos transcurridos entre la medianoche del 1 de enero de 1970 y la fecha y hora especificadas.

k) Las aplicaciones Web pueden usar la propiedad localStorage del objeto window para almacenar hasta varios megabytes de datos de cadenas de pares clave/valor en la computadora del usuario y pueden acceder a estos datos a través de sesiones y pestañas del navegador.

l) Las aplicaciones Web que necesitan acceso a los datos de pares clave/valor para sólo una sesión de navegación y que deben mantener esos datos separados entre varias pestañas pueden usar la propiedad sessionStorage del objeto window.

m) Un selector :first-child de CSS3 selecciona el primer hijo de un elemento.

n) Un selector :nth-child de CSS3 con el argumento "odd" selecciona los elementos hijos impares y uno con el argumento "even" selecciona los elementos hijos pares.
