Expresiones aritméticas en JavaScript

Pregunta: Dada la ecuación y = a * x * x * x + 7, ¿cuáles de las siguientes instrucciones de JavaScript son correctas?

a) y = a * x * x + 7;

Respuesta: Incorrecta. Falta multiplicar por una x más.

b) y = a * x * (x * x + 7);

Respuesta: Incorrecta. Los paréntesis hacen que el 7 también se multiplique por a y por x.

c) y = a * (x * x * x) + 7;

Respuesta: Correcta. Es equivalente a la ecuación dada.

d) y = a * x * x * x + 7;

Respuesta: Correcta. Coincide directamente con la ecuación.

e) y = a * (x * x * x) + 7;

Respuesta: Correcta. Los paréntesis agrupan el producto de las tres x.

f) y = a * x * (x * x + 7);

Respuesta: Incorrecta. Cambia el orden de las operaciones y, por tanto, la ecuación.
