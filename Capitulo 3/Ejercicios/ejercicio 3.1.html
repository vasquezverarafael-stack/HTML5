Complete las siguientes oraciones:

a) El atributo _____________ (que se utiliza en un solo elemento input en un formulario) resalta de manera automática el elemento input y, si se usa de manera apropiada, coloca el cursor en el campo de texto después de que el navegador carga y despliega la página.

Respuesta: autofocus.

b) Los nuevos tipos input de HTML5 tienen ______________ del lado del cliente.

Respuesta: validación automática.

c) El tipo input ____________ permite al usuario introducir un valor numérico.

Respuesta: number.

d) El tipo input ____________ se valida automáticamente de manera intrínseca cuando lo despliega el navegador como un control deslizante, ya que el usuario no puede mover el control fuera de los límites del valor mínimo o máximo.

Respuesta: range.

e) El atributo _____________ puede usarse en los tipos input para completar de manera automática la información del usuario con base en datos de entrada anteriores.

Respuesta: autocomplete.

f) El elemento _____________ proporciona una leyenda para la imagen en el elemento figure.

Respuesta: figcaption.

g) El elemento summary muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento _____________.

Respuesta: details.

h) El elemento mark nos permite _____________.

Respuesta: resaltar texto.
